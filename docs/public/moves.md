# 招式

伤害只从 `hit()` 进。招式时钟只有 `Attack.t`，对照 `Skill.start` / `duration`。招名规则在 `SCRIPTS`，键就是 `fx`。`src/game` 里不要再按招名写分支。

## 差异放哪

从上面往下，第一档盖住就停。

| 要的东西 | 放哪 |
|---|---|
| 伤害、时机、受击姿态、判定形状、弹道四轴 | `Skill` 字段 |
| 出手或收招时的倍率、治疗、击退、变身、一次特效、召唤 | `onActive` / `onFinish` |
| 固定节拍的抓（食兔者、亲亲、贴贴） | `Skill.hold` |
| 上面盖不住的过程 | `SCRIPTS[fx]` |

`fx` 仍是渲染键。注册表用同一个字符串，不要另起一套 id。

弹道四轴是运动（`motion`）、打中后留不留（`contact`）、落地（`floor`）、能不能被击落（`solid`）。不要合成一个碰撞枚举。

`hold` 只服务这三招。推落、信用、求你了的过程和末段都不一样，留在脚本里。末段变体再多一种，整段回到脚本，不要给 `Hold` 加字段。

倍率类 buff 在 `src/game/mods.ts`。定身、拉黑、狂化、国王留在角色身上：它们停时钟或换招，不是倍率。到期逻辑是闭包；一旦要做回放或联网，把账单写成数据，去掉闭包。

`Op` 只保留现有种类。新行为不是标量，就写脚本。

## 脚本

钩子是 `cast`（出手前）、`update`（招式时钟的每一帧）、`hit`（干净命中的姿态）、`shot`（飞弹的一帧）。`shot` 返回 true 表示这一帧的运动和命中都处理完了，内核不再飞它。

其余字段是内核里已经有的开关：提前收招、跳过通用连射、拖尾长度、出界仍算在场上。开关只用来点名一种现成行为。一个招需要新过程，写进钩子，不要为它再加一个开关。

需要内核私有常量的脚本，在 `src/game/combat.ts` 里写成函数，再挂到 `SCRIPTS['fx']`。招名只出现在这个键上。

## 内核留下的

格挡、连段、气、输入缓冲、定身层级、解控。这些不进招式数据。

解控（`breakout`）对外是一个统一的包：无视受控随时释放、每次释放给同一段短暂无敌、出手帧放同一道震开冲击（`combat.ts` 的 `escapePulse`）。角色只写 `breakout: true` 和它的额外效果（伤害、霸体、隐身、更长的无敌）；不要在自己的招里再写一遍震开。

作曲的持续伤害走 `hit()`，并且 `react.kind` 为 `none`：有伤害，没有硬直、连段、顿帧。不要为了「看起来像打中」把这三样加回去。

## 削防（格挡伤害）

防御条 100。按住格挡不回，松手每秒回 15。`guard <= 0` 破防：硬直 0.9 秒，1.2 秒内不能再挡。

内核默认值：被格挡的大招每段 42、重击 26、其余 15。单段大招和普通招不要写 `guardDmg`。

多段大招不许沿用每段 42，在 `Skill` 上写 `guardPlan`：

- 前轻后重，数组单调不减；最后一项供更长的段数重复使用。
- 前两段合计 < 40，保证防御被磨到 40 时仍能挡下开场两段；第一段建议 ≤ 10。
- 破防点按段数定档：2～3 段破在末段；4～6 段破在第 4～5 段；7～10 段破在第 5～6 段；11 段以上破在整段的 30%～60%，可按波次放在第二波开头。
- 交付点用 `withGuard(skill, i)` 把第 i 段的值写进 `guardDmg`；`hit()` 只读 `guardDmg`。不要按 `fx` 在核心里分支。
- 回旋类（蝶变）的 plan 是「去程 / 回程」两项，不是连续两段。
- 单段大招用 `guardDmg` 直接给值（火的故事 50）。
- 抓取（`type: 'grab'`）和 `noBlock` 是设计上的不可挡，不给 `guardDmg` / `guardPlan`：推落、墨缇丝、信用、和灯在一起、大闹一场、冰川打火姬、小摩卡要上了（已减速时）。
- 改变世界走自己的节拍格挡（`NOTE_GUARD`），不挂 plan。
- 段间隔用 0.09 秒以上：被挡硬直是 0.075 秒，低于它下一段会在格挡恢复前落下，plan 不会生效在第二段之后（九字真言已从 `.07` 调到 `.09`）。0.075 是 9 帧整，刚好接得上（忘却奏鸣），别再往下压。
- 新增或改动多段大招时，同步 `scripts/selfcheck.ts` 的 `breaksAt` / `segments` 表，跑 `npm run check`。
- 文案里引用破防值的数字随值一起改。

## 完美格挡

格挡中按任意攻击键，开 0.12 秒窗口（`PARRY_WINDOW`）；窗口里落下的被挡伤害算完美格挡。窗口落空则锁 0.35 秒（`PARRY_WHIFF_LOCK`），期间按键不开窗，防止连按。按键照常进输入队列，松开格挡可直接出手反打。

- 完美格挡：不扣防御、无格挡硬直；普通招零漏伤，大招漏伤封顶 12%；防守方回气 10，攻击方不回气。
- 近战：攻击方扣气 9，非大招且距离 260 内踉跄 0.15 秒（`parried` 在下一步结算，打断当前招）。
- 投掷物：扣气比例 0.3 → 0.6（`noSiphon` 照旧不扣）；向前发反击光球（伤害 6，内置 CD 1.5 秒）。光球带 `parryOrb`，被完美格挡不会再回光球；`solid: false`，与敌方弹丸互相穿过，不会抵消连发里的下一发。
- 顿帧 0.07 秒（普通格挡 0.018），特效 `parry`，音效 `parry`。
- CPU 只在主动格挡（`ai.block > 0`）时按难度概率触发：简单 0 / 标准 12% / 大师 30%；训练模式木桩不触发。
- 抓取、`noBlock`、破防、改变世界的节拍格挡都不涉及完美格挡。
- 触屏：格挡中攻击键按下即发轻击键，不等松手。

## 改招式时

1. 先填 `Skill`。不够再写 `onActive` / `onFinish`。还不够再挂 `SCRIPTS[fx]`。
2. 不要在 `src/game` 里写 `fx === '招名'`。允许的比较只有两种：这发是不是这招（`p.fx === skill.fx`），以及这下是不是定身的来源（`skill.fx !== defender.rootFx`）。
3. 战斗逻辑改完跑 `npm run check`。断言对不上时先查行为。不要改断言数字来迁就一次搬家。
