# MOE FIGHTERS

同屏街机格斗网页游戏，可选角色来自《BanG Dream!》。支持 1V1、2V2、同键盘双人、人机和训练场，以及手机触控操作。

灵感来源：[抽象大乱斗](https://github.com/XzJoshZ/abstract-brawl)（XzJoshZ）。本项目为独立实现的同人习作，玩法与代码均为自己编写。

## 包含什么

可选角色为《BanG Dream!》同人形象。每人有轻击、重击、空击、专属技能和满气必杀。

模式：1V1（玩家对人机）、2V2（1P 到 4P，每格可设玩家或人机，玩家最多两名）、训练场（能量持续补满、对手自动恢复，不计胜负）。两胜制，60 秒一回合；命中、受击与格挡积攒能量，100 气放必杀。

操作：A / D 移动，W / 空格跳跃，长按 S 格挡，点按 S 后闪，J / K 轻 / 重击（跳中为空击），U / I / O 技能，L 必杀，ESC 暂停。双人同键盘时，先出现的玩家用左手键，后出现的用方向键移动、小键盘出招。手机横屏游玩，左摇杆移动、右侧按键出招，手机只能占一名玩家槽位。

## 直接游玩

需要 Node.js 22 或更新版本。Windows 双击 `start.bat`，依赖会自动安装并打开浏览器。其他系统在项目目录运行：

```bash
npm install
npm run dev
```

命令行窗口要一直开着，关掉后游戏就停。这台电脑用窗口里的 Local 地址。手机和电脑连同一个局域网，用窗口里的 Network 地址打开。音效为 Web Audio 现场合成，首次操作后启动。`npm run build` 构建后可用 `npm run preview` 预览构建产物。

## 继续开发

安装 Node.js 22 或更新版本：

```bash
npm run dev      # 本地开发，改完刷新页面即可
npm run check    # 无头规则与精灵表检查
npm run build    # 类型检查并构建 dist/
```

开发面板的「部件」「键位」可直接拖改，松手写回数据文件。
