# 演出审定记录

每关审定后：剧本写回定稿、`npm run story -- seal 编号` 盖章（文字再改动，`check` 会提示重新审定）。
这里只记关键决定和通用约定；同类问题以后照这里办，不再重复讨论。

工具：`npm run story -- rehearse 3`（排练，打站位朝向、标问题）；预览 `?story=3-01&at=行号`（跳到某行截图）。

## 通用约定
- **说话对象要在说话人身前**。引擎会让说话人转向上一位说话的人；开场朝向是「面向最近的人」，所以开场站位要按第一段戏是谁跟谁说来排，不能只看名单。
- **不用「走到」挤进别人的位置**：会把对方顶开一步，看起来像推人。走位要有去处（走向出口、走向说话对象）。
- **「转身」会锁住朝向**，直到她下一次移动。背对是有意为之的戏（赌气、独自思考），要在台词转折处再转回来，不能让她背着说好几句。
- **背景和文字对不上、道具又补不了的**（梦限大写成「漆黑」、音乐室用圣域背景等）：维持现状，不改。
- **从背后被看到的台词**（「你的肩膀在发抖」「你在逃避」）适合排成背对着、被人从身后靠近。
- **幕开时的样子写在最前面**（11-25 起）：关卡开头连着的「换 / 背对 / 倒下 / 虚化」「道具 摆」、持续型「特效」会在大幕后面直接做好。开场倒在地上、背着身的人，把这几条写在 `> 亮场` 和第一句台词之前。
- **「背对」代替「转身」表达有意的背身**：转身是来回翻，背对是确定地背向某人（或最近的人）。
- **夹在中间的人朝一边**：排练汇总里的「听的人背对说话人 ×N」只要轮到她说话时会转过来，就不处理（三人以上站一排时不可避免）。
- **光点要收敛**（11-25 用户看了 3-14 后定的）：星光流失、消散、觉醒的光点都只画细长的四芒星，不垫圆形光晕（像泡泡），数量也压到原来的约 1/4；光点用正常叠加，白色纸板上也看得见。
- **特效只在文字明确写到时用**（裂隙、法阵、屏障、黑雾、光点流失、觉醒）；墨提斯写成 `墨提斯` 上台，由光点汇聚成形，不说话。
