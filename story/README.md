# 剧情写作流程

你写大纲和关卡表，Gemini 写剧本，你修改定稿，Claude 把定稿做进游戏。日常只需要双击根目录的两个文件：

- **剧情-发送.bat**：告诉你这次做什么，生成要上传的文件，并把提示词放进剪贴板。
- **剧情-接收.bat**：从剪贴板读取 Gemini 的输出，拆成每关的文件，然后检查格式。

窗口里会写清每一步怎么做，跟着做就行。下面是完整流程，方便你心里有数。

## 一次性准备
1. 双击「剧情-发送.bat」。第一次会提示你在 Gemini 里新建技能（Skills），按提示填写名称、描述、指令，再上传三个文件。指令已经放进剪贴板，文件夹会自动打开。
2. 以后 `gemini-skill/` 里的文件一有改动，发送时会提醒你去更新技能。

## 每一章
1. 在 `大纲.md` 的「## 第 N 章」下面写这一章的要点：开头和结尾的状态、5–10 条关键事件、出场角色、线索、基调。
2. 双击「发送」。关卡表还是空模板时，它会让 Gemini **先规划关卡表**：
   - 生成 `_send/chN-plan-pack.txt`，提示你**开一个新对话**，把它拖进去再粘贴提示词；
   - Gemini 会把这一章拆成 10–12 关，每关写清承接、节拍（必须发生的事）和钩子，不写台词；整章一条主线（第 2 章起，见技能「指令」的「主线与节奏」）；
   - 复制它的代码块，双击「接收」，确认后写入 `chN/关卡表.md`。
3. 按你的想法修改关卡表。这是你掌控剧情的主要地方，节拍写得越具体，剧本越不会跑偏。
4. 双击「发送」开始写剧本，**还在同一个对话里**，直接粘贴就行（提示词已附上你改过的关卡表和角色卡）。`chN/角色卡.md` 会自动生成骨架，可以补称呼和语气，不补就按原作。
5. Gemini 写完后，点代码块右上角的「复制」，双击「接收」。
   - **通过**：去 `chN/` 修改这几关的定稿。
   - **不通过**：修正提示词已经放进剪贴板，回到同一个对话粘贴，再复制、接收一次。
6. 改完定稿，双击「发送」写下一批（每批 4 关，都在同一个对话里）。你改过的定稿会自动附在提示词里，让 Gemini 跟着你的版本续写。
7. 全部写完、改完后，「发送」会让 Gemini 更新账本。复制它的输出，双击「接收」，确认改动后写入。
8. 再双击「发送」进入下一章。告诉 Claude「第 N 章导入」，就会做进游戏。

> 如果你想自己从头填关卡表，也可以：直接填好 `chN/关卡表.md` 再双击发送，它会跳过规划，生成 `_send/chN-pack.txt` 让你开新对话上传。

## 目录
| 路径 | 内容 | 谁改 |
|---|---|---|
| `大纲.md` | 全篇大纲 | 你 |
| `账本.md` | 连续性账本（事实、谁知道什么、线索、复制体真相表） | Gemini 提议，你确认 |
| `chN/关卡表.md` | 本章每一关的类型、场景、出场、节拍 | 你 |
| `chN/角色卡.md` | 本章出场角色的说话方式和称呼 | 脚本生成骨架，你补 |
| `chN/N-01.md …` | **定稿**，游戏读取的就是这些文件 | 你 |
| `chN/N-01.新稿.md` | 你已经改过定稿后，Gemini 又给了新版本时，新版本另存在这里 | 你挑着合并后删掉 |
| `raw/chN/` | Gemini 原稿和历史版本，只作对照 | 不用动 |
| `gemini-skill/` | Gemini 技能的固定内容（指令、世界观、格式、样例）；上传用的 .txt 副本会自动生成到 `_send/skill/` | 很少改 |
| `_send/` | 每次要上传或粘贴的东西（不进 git） | 自动生成 |
| `state.json` | 当前进度（不进 git） | 自动生成 |

## 通读一整章
运行 `npm run story -- overview 1`，会生成 `ch1/第1章-总览.md`：把全章定稿排成适合阅读的格式（目录、每关的场景和节拍说明、一句台词一行、演出指令用斜体）。它只用来读，改剧本还是改各关定稿，改完重新生成即可。

## 手动检查
改完定稿想确认格式，可以运行 `npm run story -- check`（检查当前章），或者 `npm run story -- check story/ch1/1-03.md`。

## 格式速查
完整规则见 `gemini-skill/剧本格式与演出指令.md`。

```
## 1-03 标题 [战斗]
@场景 tsukinomori
@节拍 B1-03a B1-03b
@线索 +C-影子-01
@开场 祥子(中左)
> 初华 走入 右
初华[开心]: 台词
祥子: 台词
旁白: 台词
@战斗 我方 祥子 | 对手 初华 | 意图: ……
---战后
祥子: 台词
```

- 表情：平常 / 开心 / 吃惊 / 防备 / 倒地。
- 位置：左 / 中左 / 中 / 中右 / 右。
- 每句台词不超过 30 字。
