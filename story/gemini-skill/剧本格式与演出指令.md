# 剧本格式与演出指令

剧本是纯文本，一关一段。脚本会逐行解析，**每一行必须是下面几种之一**，否则会被检查打回。

## 1. 标题行（每关第一行）

```
## 1-03 钟声之下 [战斗]
```

- 编号照抄关卡表。标题由你取，简短（不超过 10 个字）。
- 类型只能是：`剧情`（不打）/ `战斗` / `Boss` / `章末`。照抄关卡表。

## 2. 标记行（以 @ 开头，写在标题后面）

| 标记 | 写法 | 说明 |
|---|---|---|
| @场景 | `@场景 tsukinomori` | 照抄关卡表的场景 |
| @节拍 | `@节拍 B1-03a B1-03b` | 本关覆盖的全部节拍编号，空格分隔 |
| @线索 | `@线索 +C-影子-01 !C-钟声-02` | `+` 埋下线索，`!` 揭开线索。没有就不写 |
| @开场 | `@开场 祥子(中左) 初华(右)` | 幕开时已经站在台上的角色和位置。没人就不写 |
| @战斗 | `@战斗 我方 祥子 \| 对手 初华 \| 意图: 试探之战，祥子留了手` | 只有战斗 / Boss 关有，写在战前台词之后 |

## 3. 台词行

```
祥子: 站住。
初华[吃惊]: 诶？
薇欧拉(广播): 欢迎来到闪耀的舞台。
祥子(心声): ……这个人，真的是初华吗。
旁白: 夕阳把两人的影子拉得很长。
```

- 说话人用简称（见角色卡）。另外可以用：`旁白`、`织萌`、`？？？`（身份未揭晓时）。
- `[表情]`：这句话开始时换成哪张纸板，之后保持不变，直到下次换。只能是：
  - `平常`（默认，戒备站姿）
  - `开心`（开心、惊喜、兴奋）
  - `吃惊`（吃惊、受打击、被说中）
  - `防备`（害羞、防备、为难、无奈）
  - `倒地`（倒下，搞笑或战败时用）
- `(标注)` 只能是：`广播`（不在场的人对全场说话，比如薇欧拉）、`心声`（内心独白）、`伪装`（用假身份说话）。
- 说话人必须在场（在 @开场 里或者已经走入），广播和心声除外。
- 每句不超过 30 字，最长不能超过 56 字。

## 4. 演出指令行（以 > 开头）

角色动作（`> 角色 动作 [参数]`）：

| 指令 | 例子 | 效果 |
|---|---|---|
| 走入 | `> 初华 走入 右` | 纸板摇摆着从对应一侧走到该位置 |
| 走到 | `> 祥子 走到 中` | 在台上移动到另一个位置 |
| 退场 | `> 初华 退场 右` | 从一侧走下台 |
| 转身 | `> 祥子 转身` | 纸板翻面，转向另一边 |
| 面向 | `> 祥子 面向 睦` | 转过去对着某人（有人从身后走进来、要对她说话时用） |
| 背对 | `> 祥子 背对` / `> 祥子 背对 素世` | 背向最近的人（或写明背向谁），一直背着，直到她再移动或「转身」。写在开场第一句台词之前，幕开时就已经背着站好 |
| 靠近 | `> 初华 靠近 祥子` | 朝对方走近一步 |
| 后退 | `> 初华 后退` | 后退一步 |
| 跳 | `> 初华 跳` | 原地小跳（开心或吓一跳） |
| 倒下 | `> 祥子 倒下` | 整张纸板往后倒 |
| 起身 | `> 祥子 起身` | 纸板立起来 |
| 发抖 | `> 初华 发抖` | 快速抖动（生气、害怕） |
| 换 | `> 初华 换 防备` | 不说话时换表情纸板 |
| 虚化 | `> 初华 虚化` | 身体变得半透明、一闪一闪（快要消失） |
| 消散 | `> 初华 消散` | 原地化作金色光点，从脚往上散去，之后算下台（不是走下去） |
| 复制体翻面 | `> 初华 复制体翻面` | 揭晓用：纸板转过去，露出背面。**只在关卡表要求揭晓时用** |

全场演出（`> 指令`）：

| 指令 | 效果 |
|---|---|
| `> 震屏` | 画面震一下 |
| `> 暗场` / `> 亮场` | 舞台灯熄灭 / 亮起（转场、时间流逝） |
| `> 闪回开始` / `> 闪回结束` | 舞台蒙上褪色滤镜，表示回忆 |
| `> 立绘 祥子` | 大号立绘纸板弹出约 1 秒。**每章最多两三次**，只用在最关键的瞬间 |
| `> 停顿` | 沉默一拍 |

- **幕开时的样子**：写在关卡最开头、连在一起的「换 / 背对 / 倒下 / 虚化」「道具 … 摆」和持续型「特效」，会在大幕拉开之前就做好（幕一拉开她就已经倒在地上、背着身、星门已经立在台上）。
- 位置只有 5 个：`左` `中左` `中` `中右` `右`。同屏最多 6 人（站位只有 5 个，6 人时游戏会自动均匀铺开，位置写个大概即可）。
- 清单里没有的动作，写进台词或旁白里。
- `退场` 后面可以写 `左` / `右` 指定从哪一侧下台；不写就从近的一侧下。
- **已经现身的梦魇**（公开袭击、已被识破、和本人同时出现）写成「梦魇 + 简称」上台，例如 `> 梦魇海铃 走入 右`。舞台上是暗紫色纸板、影子极深，和本人一眼就能分开。它被打败时写 `> 梦魇海铃 倒下`，纸板会自动化光消散，之后算下台。
- **还在伪装中的复制体**（角色们还没发现）照常写本人简称，不要提前写成「梦魇X」。
- 旁白里写到梦魇出现、扑上来、拦路时，让它真的上台（同屏最多 6 人），不要只在旁白里出现、让角色对着空气说话。
- **墨提斯**（睦的另一个人格实体化出来的分身）写成 `墨提斯` 上台：`> 墨提斯 走入 左`。她不是走上来的，而是在那个位置由光点汇聚成形；样子是睦的纸板，半透明的冷蓝色，浮在地上。`> 墨提斯 退场` 是化光散去；写了方向（`> 墨提斯 退场 左`）就是护送别人一起走下台。墨提斯不说话（睦替她说），只做走位类动作，不算进同屏 6 人。

### 特效（`> 特效 名字 [参数]`，收掉写 `> 特效 收 名字`）

代码画的光效，用在剧情的关键瞬间。前五种开了以后会一直留在台上，直到「收」或这一段演完；觉醒演完自己消失。

| 特效 | 例子 | 效果 |
|---|---|---|
| 星光流失 | `> 特效 星光流失` / `> 特效 星光流失 初华` | 金色光点不断往上飘走。写角色就是从她身上流走；台上开着裂隙时，光点会被吸进裂隙 |
| 裂隙 | `> 特效 裂隙 中` | 天上撕开一道发紫光的空间裂缝（只能写位置，默认正中） |
| 法阵 | `> 特效 法阵 喵梦` | 脚下一座黑色法阵，暗紫符文转动、黑光往上冒、偶尔窜过电流（写角色或位置） |
| 屏障 | `> 特效 屏障 灯` | 角色身前张开一面星光屏障。之后写 `> 震屏`，屏障会被打得一亮；`> 特效 收 屏障` 时碎成光片 |
| 黑雾 | `> 特效 黑雾` / `> 特效 黑雾 梦魇初华` | 黑雾从地面漫上来、舞台变暗；写角色就是黑雾缠在她身上 |
| 觉醒 | `> 特效 觉醒 素世` | 一道柔和的光柱落在她身上，光点上升、整个人被照亮（约 2.5 秒）。只用在角色第一次觉醒闪耀之力的那一刻 |

- 特效是锦上添花：一关最多用两三种，写在文字提到它的那一句前面。
- 只用上面这几种。清单里没有的效果写进旁白。

### 道具（`> 道具 名字 动作 [参数]`）

舞台上的纸板布景。现有道具：`星门`（刻五道凹槽的石门）、`囚笼`（星光囚笼）、`碎石`（星门上掉下的残片）、`星盘`（古老星盘）、`星轨仪`（吊在空中的星轨仪器）。

| 动作 | 例子 | 效果 |
|---|---|---|
| 摆 | `> 道具 星门 摆 中` / `> 道具 囚笼 摆 初华` | 摆上台：写位置，或者写角色名（摆在她所在的地方，囚笼就是罩住她） |
| 撤 | `> 道具 星门 撤` | 收走 |
| 亮 | `> 道具 星盘 亮` / `> 道具 星门 亮 3` | 发光；星门写数字 = 亮起几道凹槽 |
| 灭 | `> 道具 星门 灭` | 光全部熄掉 |
| 透光 | `> 道具 星门 透光` | 星门门缝透出光 |
| 合缝 | `> 道具 星门 合缝` | 星门旁的石缝合拢一点 |
| 锁 / 碎 | `> 道具 囚笼 锁` / `> 道具 囚笼 碎` | 囚笼缠上黑锁链 / 锁链和笼子一起碎成光屑 |
| 落 | `> 道具 碎石 落 星门` | 从上方掉下来，落地亮一圈光；写道具名就落在那件道具脚边 |
| 随 | `> 道具 碎石 随 虹夏` | 拿在某个角色身前，跟着她走 |
| 震 | `> 道具 星门 震` | 抖一下 |

- 只用上面这几件道具。清单里没有的物品写进台词或旁白。

## 5. 战后分隔

战斗 / Boss 关在 @战斗 之后写一行 `---战后`，下面是战后台词。@战斗 和 ---战后 之间什么都不写。

## 6. 篇幅预算（台词句数，含旁白）

| 类型 | 句数 |
|---|---|
| 剧情 | 30–45 |
| 战斗 | 战前 14–22，战后 6–10 |
| Boss | 战前 18–28，战后 8–12 |
| 章末 | 40–55 |
