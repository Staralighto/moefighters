# 样例关

> 本文件**只示范格式和写法**，剧情内容不作数，不要沿用其中的情节和线索。正式剧情以资料包为准。

下面是一关完整、能通过检查的战斗关。注意这些写法：
- 表情只在情绪变化时标一次，后面的台词保持不变；
- 演出指令很少，只在需要的地方出现；
- 战前有“为什么非打不可”的理由；
- 线索放在旁白里一笔带过，不点破。

```
## 0-01 钟声之下 [战斗]
@场景 tsukinomori
@节拍 B0-01a B0-01b
@线索 +C-样例-01
@开场 祥子(中左)

> 亮场
旁白: 傍晚的月之森，校门的钟一下也没有响。
祥子[防备]: ……是月之森。可是，太安静了。
> 初华 走入 右
初华[开心]: 小祥！太好了，你也在这里。
祥子: 站住。
初华[吃惊]: 诶？
祥子: 那个自称薇欧拉的声音，你也听到了吧。
初华[平常]: 嗯……说什么打倒对手就能实现愿望。
祥子: 在弄清楚之前，我谁都不信。包括你。
旁白: 夕阳把两人的影子拉得很长。
初华[防备]: 小祥，你是要和我打吗？
祥子: 只是确认。确认你还是你。
@战斗 我方 祥子 | 对手 初华 | 意图: 试探之战，祥子留了手，初华几乎不还击
---战后
初华[倒地]: ……好痛。下手还是这么不留情呢。
祥子[平常]: 能喊痛，大概是真的。
> 祥子 转身
祥子: 走吧。天黑之前，先找到其他人。
```
